🏨 Hotel Management System

A complete and structured Hotel Management System Database built with Microsoft SQL Server.

This project is designed to provide a reliable relational database for managing the main operations of a hotel, including rooms, room types, guests, reservations, payments, employees, and other essential hotel services.

🎯 Project Overview

The goal of this project is to design and develop a well-structured hotel database that is:

- Organized
- Reliable
- Scalable
- Easy to maintain
- Ready to integrate with a C# application

The database follows relational database principles and uses Primary Keys, Foreign Keys, Constraints, Indexes, Views, and Stored Procedures to maintain data integrity and support efficient hotel management.

✨ Main Features

- 🛏️ Room and room type management
- 👤 Guest management
- 📅 Reservation management
- 💳 Payment management
- 👨‍💼 Employee management
- 🧾 Invoice management
- 🛎️ Hotel services management
- 🔐 User and role management
- 📊 Hotel statistics and reports
- 🔎 Search and filtering
- 🏷️ Room status management
- 📜 Room status history
- 🧩 Room amenities management
